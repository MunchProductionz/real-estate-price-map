# Real Estate Price Map 🗺️
Visualizes in real-time which postcodes are within the users price range given the user's input with regards to income, loan capabilities and preference filters.

## Test it out
Try it out: [Real Estate Price Map](https://real-estate-map.eivindnesje.no/) 🗺️

## Details
The user's max possible purchase price is calculated with a simple expression that grows linearly with income, based of the max loan amount being 5x the user's income.

## Colors 🎨
- Blue: Can afford
- Yellow: Can afford, but the user is less than 20% above the average price
- Gray: Cannot afford
